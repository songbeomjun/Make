# VoxelCraft Web v1.1

브라우저에서 바로 실행하는 오리지널 3D 복셀 샌드박스 게임입니다.

## 실행
1. `index.html`을 브라우저에서 엽니다.
2. `index.html`은 Three.js를 CDN에서 불러오므로 인터넷 연결 상태에서 실행하세요.
3. iPhone/iPad에서는 Safari 가로 화면을 권장합니다.

## 조작
- PC: WASD 이동, Space 점프, 마우스 시점, 좌클릭 채굴, 우클릭 설치, 1~9 슬롯, E 인벤토리, ESC 메뉴
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 화면 드래그 시점, 점프/채굴/설치 버튼

## 주요 기능
- 시드 기반 절차적 지형
- 평원 / 숲 / 사막 / 설원
- 물, 동굴, 광석, 나무
- 청크 단위 메시 생성 및 블록 수정
- 블록 채굴/설치
- 9칸 핫바 + 블록 인벤토리
- 플레이어 충돌, 중력, 점프, 수영, 낙하 피해
- 낮/밤, 해/달, 구름, 안개
- 간단한 블록형 동물
- 로컬 저장/이어하기
- 데스크톱 Pointer Lock
- iOS/Android 터치 조작
- 더블탭 확대 및 브라우저 제스처 억제

## 웹에 올리기
GitHub Pages 기준:
1. 새 저장소에 이 폴더의 `index.html`을 업로드합니다.
2. 저장소 Settings → Pages
3. Deploy from a branch → `main` / `(root)` 선택
4. 생성된 Pages 주소를 Safari/Chrome에서 엽니다.

원본 Minecraft/Mojang 코드, 텍스처, 사운드 파일은 포함하지 않습니다.
