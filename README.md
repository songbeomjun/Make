# VoxelCraft Ultra v2

브라우저에서 실행되는 고품질 오리지널 3D 복셀 샌드박스입니다.

## 핵심 업그레이드
- 32×32 로컬 PNG 블록 텍스처 아틀라스
- 텍스처 기반 핫바 / 인벤토리 / 1인칭 손 블록
- 128×128 월드, 64 높이
- 강, 해안, 평원, 숲, 사막, 설원, 고지대
- 동굴 / 광석 / 나무 / 노출 바위
- 교차 평면 방식 잔디 / 꽃 / 마른 덤불
- 블록 파괴 균열 오버레이
- 양 / 돼지 / 소 / 닭 형태의 고급 블록형 동물
- 그림자, 톤 매핑, 안개, 낮밤, 별, 사각 해/달
- 물속 화면 효과
- 청크 분할 로딩으로 모바일 프리즈 감소
- 저장 / 이어하기
- iPhone 터치 조이스틱, 시점 드래그, 점프 / 채굴 / 설치
- 더블탭 확대 방지

## 실행
`index.html`을 웹 서버에서 실행하는 것을 권장합니다.
GitHub Pages에 폴더 구조 그대로 업로드하면 됩니다.

## 인터넷
Three.js는 CDN을 사용하므로 최초 실행 시 인터넷 연결이 필요합니다.
게임용 텍스처와 기타 시각 자산은 ZIP 안에 포함되어 있습니다.

## 리소스 정책
Minecraft 공식 비주얼은 색감, 픽셀 밀도, 블록 면 구성의 참고 자료로만 사용했습니다.
ZIP에는 Mojang의 원본 텍스처/사운드/코드를 포함하지 않습니다.
